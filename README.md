# MICRO LAB FUSION 3.0 — обновление интерфейса и учебного маршрута

Это **единое действующее приложение**, а не отдельный демонстрационный макет. FUSION работает поверх MICRO LAB Discovery 2.0 и сохраняет данные 27 экзаменационных билетов, 31 учебного раздела, 67 авторских задач (26 ситуационных), 12 SVG-моделей, WebGL 3D-атласа, микроскопа и практических упражнений.

## Новое в FUSION

- **GLASS SPACE** — светлая адаптивная главная страница с текущим прогрессом, поиском, персональным следующим уроком и карточками пяти пространств.
- **NEON LAB** — ранее реализованный WebGL-атлас бактерии интегрирован в тёмный лабораторный интерфейс; при отсутствии WebGL доступна 2D-схема.
- **SCIENCE ATLAS** — новое оформление библиотеки билетов и тематических лекций без замены учебного содержания.
- **MICRO MISSION** — три цели, основанные на реально сохранённых данных: пройденные уроки, решённые задания, повторённые билеты. Условные XP и «победы» не создаются.
- **SCOPE STATION** — отдельная тёмная/янтарная атмосфера для действующего виртуального микроскопа.
- **Тема оформления** — ручной выбор светлой/тёмной темы с локальным запоминанием; **навигация** — боковая панель на компьютере и нижняя панель с «Ещё» на iPhone/iPad.
- **Сохранённое обучение** — не изменяются ключи локального прогресса, вопросы тренажёра, содержимое билетов и существующие механики. Кнопки экспорта/импорта JSON перенесены без создания новых копий.

### Как установить

Распакуйте `MICRO_LAB_FUSION_3_0_GitHub_Pages.zip` и загрузите его содержимое непосредственно в корень GitHub Pages. Не создавайте дополнительную папку над `index.html`. Перед обновлением рекомендован экспорт JSON-прогресса. Подробности в `DEPLOY.md`.

### Ограничения

Это завершённое **техническое дизайнерское обновление**, но не свидетельство независимой научной рецензии. Извлечённые из PDF данные могут содержать ошибки; все 67 авторских вопросов и объяснения требуют проверки. Изображения в виртуальном микроскопе синтетические. Испытания на физическом iPhone/iPad/Safari и проверки офлайн-обновлений после реального размещения остаются необходимыми.

# MICRO LAB Discovery 2.0 — расширенный учебный релиз

**Публикация:** содержимое ZIP загрузите в корень репозитория GitHub Pages (`index.html` должен быть в корне). Всё приложение работает без сервера и без внешних зависимостей. WebGL-модель генерируется локально, без CDN. Для offline первым запуском необходимо открыть сайт по HTTPS и дождаться кэширования данных.

## Новое в Discovery 2.0

- **3D-атлас бактерии:** реальная WebGL-геометрия, свободный поворот/масштабирование, разрез, отключаемые слои, Gram+/Gram−, выбор структуры и задание «Найди структуру». При отсутствии WebGL показывается 2D-альтернатива. Структуры схематичны и представлены не в масштабе; не используются внешние 3D-модели.
- **Виртуальный микроскоп:** синтетические изображения трёх типовых морфологических картин с фокусом, условным увеличением и самопроверкой. Рисунки не являются фото препаратов и не подходят для диагностики.
- **Три ситуационных кейса** с объяснениями и **визуальный экзамен** — собирание четырёх логических этапов окраски по Граму без практического протокола.
- **Билеты:** фиксированная карта 81 заголовка исходного конспекта (по три в каждом из 27 билетов), предотвращает путаницу со вложенными нумерованными списками. Требуется независимая сверка извлечённого текста с изображениями страниц PDF.
- **Прогресс:** постоянные идентификаторы тем, однократный перенос данных прошлой версии, проверка и локальная резервная копия перед импортом. Мобильное меню с видимым «Ещё», исправленная экскурсия. PNG-иконки для iOS/PWA.

**Подтверждённое число уроков: 31.** Исходный массив содержит 48 записей, но часть из них — фрагменты, а не полноценные уроки. Все 27 исходных билетов доступны отдельно. 67 авторских тренировочных заданий, 26 из них ситуационные; в Discovery добавлены ещё три самостоятельных кейса (не входят в 67). 12 прежних SVG-моделей сохранены.

**Ограничения:** это технически функциональная и обучающая сборка, а не экспертно выверенный курс. Все авторские объяснения, кейсы и задания требуют предметной проверки. Scientific/Source режим отличает текст исходного конспекта от дополнительных объяснений. Браузерный smoke-тест Chromium не заменяет проверку в настоящем Safari iOS.

# История функциональной сборки

Адаптивное веб-приложение для подготовки к экзамену по микробиологии (iPhone, iPad, настольный браузер). Размещается как статический сайт на GitHub Pages без сервера.

## Состав
- 27 билетов из предоставленного PDF, полнотекстовый поиск, исходный извлечённый текст, устная самопроверка по выделенным вопросам и прогресс.
- 31 тематический урок с исходными материалами, режимами «простым языком» и «научный», карточками и пошаговыми моделями.
- Предметный тренажёр из **67 авторских заданий (включая 26 ситуационных)** с ответами и объяснениями: охват первой темы каждого из 27 билетов, а также дополнительных ключевых понятий. Отдельный режим ошибок и тренировка по номеру билета. **Это дополнительные учебные вопросы, а не буквальное воспроизведение PDF.**
- Отдельный смешанный экзамен с тестовыми и открытыми вопросами, личная статистика, интервальное повторение.
- Экспорт/импорт прогресса в JSON (включая результаты предметного тренажёра и билеты).
- Манифест приложения, иконка, офлайн-кэширование основных файлов после первого успешного открытия по HTTPS.
- Интерфейс адаптирован для узких экранов, поддерживается клавиатура и настройка размера текста.

## Публикация
1. Создайте репозиторий на GitHub.
2. Загрузите **все файлы из архива непосредственно в корень** репозитория, а не в дополнительную папку: `index.html`, `app.js`, `trainer.js`, `data.js`, `tickets.js`, `sw.js`, `manifest.json`, `icon.svg`.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.
4. После публикации откройте HTTPS-адрес в Safari на iPhone/iPad. Меню «Поделиться» → «На экран Домой».
5. При обновлении версии выполните перезагрузку сайта с интернетом, чтобы сервис-воркер загрузил свежие файлы.

## Источники и достоверность
- Основной источник: PDF пользователя «Микра билеты с пояснениями», 89 страниц. `tickets.js` содержит автоматически извлечённый текст всех 27 билетов. В нём могут быть ошибки распознавания структуры, переноса строк и отсутствовать схемы/изображения из оригинального PDF.
- Дополнительный общедоступный справочник для общих микробиологических определений и проверки авторских вопросов: OpenStax Microbiology — https://openstax.org/books/microbiology/pages/index . В учебнике рассматриваются прежде всего медицинские примеры; ветеринарные нюансы сверяйте с исходными билетами и преподавателем.
- Упрощённые объяснения специально написаны только для части тем; в остальных случаях режим представляет **подборку предложений исходного конспекта**, а не полную переработанную лекцию.
- Пошаговые модели описывают общие механизмы; не для каждого билета есть индивидуальная предметная анимация.
- Вопросы с выбором ответа в предметном тренажёре составлены вручную, но **не проходили независимую экспертную рецензию**. Открытые ответы и устные билеты оценивает сам пользователь.

**Статус:** технический релиз для публикации и самостоятельного использования. Полностью экспертно выверенным учебным курсом её считать нельзя без сверки извлечённого PDF и научной редакции всех лекций. Встроенный материал — учебный, не ветеринарный диагностический протокол.

## Визуальные симуляторы (обновление 1.1)

В уроках, относящихся к иммунитету, энергетическому обмену, лабораторной диагностике и передаче инфекции, добавлены SVG-модели с перемещением и изменением объектов. Это **упрощённые концептуальные модели**, а не биофизически точные симуляции. В остальных темах, для которых соответствующая модель не подготовлена, этот блок не показывается.

## Visual 2.0 — интерактивная лаборатория

Новый пункт меню «Визуальная лаборатория» открывает четыре интерактивные SVG-модели: график роста популяции (ползунок по времени), окраску по Граму (четыре стадии), диско-диффузионную модель (условная зона задержки роста) и фагоцитоз (четыре стадии). При выборе соответствующей темы одна из моделей появляется также в уроке. Управление: ползунок, предыдущий/следующий этап, воспроизведение/пауза. Эти модели — концептуальные иллюстрации, не реальные измерения и не диагностические критерии. Численные шкалы графика и зоны задержки роста условны.

## Visual 2.1 — обучение при первом запуске
При первом открытии приложение показывает короткое пошаговое обучение: подсвечивает реальные пункты навигации, объясняет назначение каждого, позволяет переходить назад/вперёд или пропустить. После завершения или пропуска обучение больше не показывается автоматически; повторный запуск — кнопка «? Как пользоваться» в шапке. Флаг прохождения хранится локально в браузере.

## Visual 3.0 — расширенная лаборатория
Добавлены три интерактивные SVG-модели: бинарное деление бактерии, специфическое связывание антигена и антитела, обобщённый цикл репродукции вируса. Теперь в визуальной лаборатории семь моделей. Все модели имеют ползунок, покадровый переход, автопроигрывание, пояснения и пометку об учебном характере. В соответствующих тематических уроках новые модели появляются автоматически. Сохранены экскурсия по интерфейсу и прежние разделы. Версия офлайн-кэша обновлена.

## Visual 4.0 — дополнительные предметные модели

Добавлены ещё четыре SVG-модели: горизонтальный перенос генов (трансформация, трансдукция, конъюгация), сравнение оболочек грамположительных и грамотрицательных бактерий, условные кривые первичного/вторичного иммунного ответа и разрыв цепи передачи инфекции. Всего 11 моделей. Они открываются в «Визуальной лаборатории» и в соответствующих уроках. Модели концептуальные; данные на графиках условные.

Научная справка для новых моделей: OpenStax Microbiology, глава 11.6 — https://openstax.org/books/microbiology/pages/11-6-how-asexual-prokaryotes-achieve-genetic-diversity . Дополнительные модели не являются прямыми цитатами из исходного PDF. При необходимости используйте оригинальные билеты для формулировок экзамена.

**Незавершённые критерии качества:** индивидуальные лекции на двух уровнях для каждого вопроса всех 27 билетов, экспертная сверка всего извлечённого текста с PDF и уникальные задания по каждому вопросу. Техническое тестирование не заменяет научную рецензию.

## Visual 6.4 — исправление клавиатурного управления
- В предметном тренажёре работают клавиши 1–3 для выбора отображаемого варианта и Enter для следующего вопроса после ответа.
- При смене вопроса прежний обработчик клавиатуры удаляется.
- Связь авторских заданий с номером билета предварительная: это учебная группировка, не постраничная научная сверка.
- Автоматическая проверка структуры: 67 заданий, 26 ситуационных задач, 27 групп, ошибок не обнаружено. Проверка в Safari остаётся открытой.

## Visual 6.5 — надёжность тренажёра и обновления
- Обработчик клавиатуры снимается при выходе из тренажёра и при открытии билета; Enter не перехватывается у кнопок и ссылок.
- Навигация приложения использует network-first при наличии интернета, с офлайн-резервом из кэша.
- Важно: для обновления JS с уже установленным service worker может понадобиться повторное открытие страницы после установки нового кэша.


## Visual 6.6 — проверка первоисточника в тренажёре
После ответа можно раскрыть автоматически подобранный фрагмент из текста соответствующего билета. Совпадение по словам не является научной верификацией; при сомнениях откройте полный билет и сверяйтесь с оригинальным PDF. Исправлена подпись кнопки перехода.


## Visual 6.7 — безопасная сверка
Автоматический поиск выдержек из исходного билета теперь использует порог совпадения. При недостатке совпадений показывает предупреждение, а не случайный фрагмент. Это навигационный инструмент, не научная экспертиза.
