# MICRO LAB — финальная функциональная сборка 1.0

Адаптивное веб-приложение для подготовки к экзамену по микробиологии (iPhone, iPad, настольный браузер). Размещается как статический сайт на GitHub Pages без сервера.

## Состав
- 27 билетов из предоставленного PDF, полнотекстовый поиск, исходный извлечённый текст, устная самопроверка по выделенным вопросам и прогресс.
- 41 тематический раздел с исходными материалами, режимами «простым языком» и «научный», карточками и пошаговыми моделями.
- Предметный тренажёр из **41 вручную составленных заданий** с ответами и объяснениями: охват первой темы каждого из 27 билетов, а также дополнительных ключевых понятий. Отдельный режим ошибок и тренировка по номеру билета. **Это дополнительные учебные вопросы, а не буквальное воспроизведение PDF.**
- Отдельный смешанный экзамен с тестовыми и открытыми вопросами, личная статистика, интервальное повторение.
- Экспорт/импорт прогресса в JSON (включая результаты предметного тренажёра и билеты).
- Манифест приложения, иконка, офлайн-кэширование основных файлов после первого успешного открытия по HTTPS.
- Интерфейс адаптирован для узких экранов, поддерживается клавиатура и настройка размера текста.

## Публикация
1. Создайте репозиторий на GitHub.
2. Загрузите **все файлы из архива непосредственно в корень** репозитория, а не в дополнительную папку: `index.html`, `app.js`, `trainer.js`, `data.js`, `tickets.js`, `sw.js`, `manifest.json`, `icon.svg`.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.
4. После публикации откройте HTTPS-адрес в Safari на iPhone/iPad. Меню «Поделиться» → «На экран Домой».
5. При обновлении версии выполните перезагрузку сайта с интернетом, чтобы сервис-воркер загрузил свежие файлы.

## Источники и достоверность
- Основной источник: PDF пользователя «Микра билеты с пояснениями», 89 страниц. `tickets.js` содержит автоматически извлечённый текст всех 27 билетов. В нём могут быть ошибки распознавания структуры, переноса строк и отсутствовать схемы/изображения из оригинального PDF.
- Дополнительный общедоступный справочник для общих микробиологических определений и проверки авторских вопросов: OpenStax Microbiology — https://openstax.org/books/microbiology/pages/index . В учебнике рассматриваются прежде всего медицинские примеры; ветеринарные нюансы сверяйте с исходными билетами и преподавателем.
- Упрощённые объяснения специально написаны только для части тем; в остальных случаях режим представляет **подборку предложений исходного конспекта**, а не полную переработанную лекцию.
- Пошаговые модели описывают общие механизмы; не для каждого билета есть индивидуальная предметная анимация.
- Вопросы с выбором ответа в предметном тренажёре составлены вручную, но **не проходили независимую экспертную рецензию**. Открытые ответы и устные билеты оценивает сам пользователь.

**Статус:** завершённая техническая сборка для публикации и самостоятельного использования. Полностью экспертно выверенным учебным курсом её считать нельзя без сверки извлечённого PDF и научной редакции всех лекций. Встроенный материал — учебный, не ветеринарный диагностический протокол.
