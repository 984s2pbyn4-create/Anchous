# MICRO LAB — план доработки

## Этап 1. Надёжность анимаций — выполнен в Visual 5.2
- Единый контроллер таймеров для всех моделей, включая встроенные в лекции.
- Автоматическое воспроизведение при открытии модели.
- Пауза останавливает таймер; новая модель останавливает старую.
- Остановка при уходе со страницы, переключении вкладки и скрытии модели.
- Ручное изменение этапа/ползунка ставит воспроизведение на паузу.
- Уважение системной настройки «Уменьшение движения».
- Браузерные регрессионные тесты паузы, переключения и автоматического запуска.

## Этап 2. Научная редактура — в работе (Visual 5.3)

- Сверка формулировок с PDF и индивидуальная редактура вопросов остаются открытыми.

- Для каждого экзаменационного вопроса составить научную и простую версии объяснения.
- Отделить сведения исходного конспекта от дополнительных источников и примеров.

## Этап 3. Содержательные визуализации — предстоит
- Создать визуальные модели по ключевым механизмам каждого раздела.
- Добавить понятные легенды, проверку понимания и пояснения к переходам.
- Для количественных графиков обозначать условные данные и допущения.

## Этап 4. Тестирование и экзамен — предстоит
- Проверенные предметные вопросы для каждого билета, а не шаблонные отвлекающие ответы.
- Разные форматы заданий: выбор, соответствие, последовательность, клинический случай.
- Разбор ошибки и ссылка на конкретный фрагмент урока.

## Этап 5. Релизная проверка — предстоит
- Автотесты основных сценариев, доступности и сохранения прогресса.
- Ручная проверка в Safari на iPhone/iPad после публикации.
- Проверка GitHub Pages, офлайн-режима, версии кэша и инструкции.
- Выпуск финального архива только после выполнения этапов 2–5.
