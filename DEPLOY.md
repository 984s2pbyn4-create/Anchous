# Как установить MICRO LAB FUSION 3.1 Dark Edition на GitHub Pages

1. Создайте новый репозиторий на GitHub или откройте существующий MICRO LAB.
2. Если используется прежняя версия, в ней сначала выберите **Сохранить прогресс** и скачайте JSON-файл. Браузерный прогресс сохраняется по домену, поэтому важно не менять адрес опубликованного сайта.
3. Распакуйте архив и загрузите **все файлы из архива непосредственно в корень** выбранного репозитория, включая `index.html`, `discovery.js`, `discovery.css`, `fusion.js`, `fusion.css`, `sw.js`, `tickets.js`, `data.js` и иконки PNG.
4. Откройте Settings → Pages → Build and deployment → Deploy from a branch. Выберите `main` и `/(root)`, сохраните настройки.
5. Перейдите по выданному GitHub Pages URL (HTTPS). В новой версии должна появиться надпись **FUSION**, новая главная страница и пункт **Миссии**.
6. Откройте **Исследовать → 3D-атлас** и проверьте вращение пальцем, переключение оболочек и викторину. Затем проверьте раздел «Микроскоп» и открытие одного из 27 билетов.
7. Для использования офлайн **сначала откройте сайт с интернетом**. Дождитесь начальной загрузки, после чего проверьте отключение сети; актуальный Service Worker должен успеть закэшировать ресурсы. Работоспособность офлайн на вашем устройстве пока не подтверждена.
8. Если старая версия остаётся в кэше, закройте и снова откройте приложение; в Safari при необходимости обновите вкладку или данные сайта. Перед очисткой данных сайта обязательно экспортируйте прогресс.

**Важно:** файл PDF-оригинала в этот архив не входит. Приложение содержит извлечённые тексты билетов и дополнительные авторские объяснения. При подготовке к экзамену сверяйте спорные детали с первоисточником и преподавателем.
